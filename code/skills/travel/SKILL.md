# 差旅标准（演示数据）

| 项目 | 一线城市 | 其他城市 |
| --- | --- | --- |
| 住宿 / 晚 | 600 元 | 400 元 |
| 餐补 / 天 | 100 元 | 80 元 |

- 交通：800 公里以内坐高铁二等座；超过 800 公里可以坐飞机经济舱。
- 超标：事前在 OA 提「超标申请」，部门负责人批准后才能报销；事后补批不受理。

回答时：先问清楚城市（如果用户没说），再给对应额度；涉及超标，必须提醒要事前审批。
